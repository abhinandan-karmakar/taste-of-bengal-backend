Authentication
--------------
**
Endpoint: POST /api/v1/auth/register
Authentication : Not required
Method : POST
Description : New user should register first of all
Request body :
{ 
 name : String
 email : String
 password : String
 phone : String
}
Success response : 
201 (HttpStatus.CREATED) - User registered successfully
Error : 
400((HttpStatus.BAD_REQUEST) - Invalid input
409 (HttpStatus.CONFLICT) - Email/Phone already exist

**
Endpoint : POST /api/v1/auth/login
Authentication : Not required
Method : POST
Description : User should login first to use the application
Request body :
{ 
 email : String
 password : String
}
Success response : 
200 (HttpStatus.OK) - { return TOKEN }
Error : 
401(HttpStatus.UNAUTHORIZED) - Invalid input

**
Endpoint : POST /api/v1/auth/refresh
Authentication : not required
Method : POST
Description : Fetch the refresh token from cookie and generate a new access and refresh token and invalid the old refresh token.
Request body : None
Success response : 
200 (HttpStatus.OK) - { return TOKEN }
Error : 
Spring security error/exception.

**
Endpoint : POST /api/v1/auth/logout
Authentication : not required
Method : POST
Description : Invalid the refresh token.
Request body :None
Success response : 
200 (HttpStatus.OK) - { return TOKEN }
Error : 
Spring Security Error/ Exception.
